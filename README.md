# FoodAPS Household Food Spending Analysis

## Project Overview

This project examines the relationship between the frequency of preparing
dinner at home and household food spending among U.S. households.

## Research Question

How is the frequency of preparing dinner at home associated with household
food spending among U.S. households?

## Data Source

This project uses data from the U.S. Department of Agriculture (USDA)
National Household Food Acquisition and Purchase Survey (FoodAPS).

The data were obtained from the USDA Economic Research Service website
using Python web scraping.

## Datasets Used

- faps_household_puf.csv
- faps_fahevent_puf.csv
- faps_fafhevent_puf.csv

## Analysis

The project includes:

- Data acquisition
- Data cleaning and preparation
- Exploratory data analysis
- Data visualization
- Correlation analysis
- Simple linear regression
- Multiple linear regression
