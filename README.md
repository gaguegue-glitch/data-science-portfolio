# Projects

## Project 1: FoodAPS Household Food Spending Analysis

### Research Question

How is the frequency of preparing dinner at home associated with household
food spending among U.S. households?

### Project Overview

This project uses data from the USDA FoodAPS National Household Food
Acquisition and Purchase Survey to examine the relationship between
preparing dinner at home and household food spending.

The analysis includes:

- Data acquisition and preparation
- Data cleaning
- Aggregation and merging of FoodAPS datasets
- Exploratory data analysis
- Data visualization
- Correlation analysis
- Simple linear regression
- Multiple linear regression
- Interpretation of results
- Discussion of limitations and ethical considerations

## Project 2: Telecom Customer Churn Prediction

### Prediction Question

Can customer characteristics and service usage patterns be used to predict
whether a telecommunications customer will churn?

### Project Overview

This project develops and evaluates machine-learning models for predicting
customer churn in the telecommunications industry.

The dataset contains 7,043 telecommunications customers and includes
customer characteristics, account information, service information,
charges, and service-usage measures.

The project includes:

- Data cleaning and preparation
- Exploratory data analysis
- Feature selection
- Train-test splitting
- Missing-value imputation
- Baseline classification
- Logistic Regression
- Random Forest classification
- Model evaluation using accuracy, precision, recall, and F1-score
- Confusion matrix analysis
- Random Forest feature importance
- Logistic Regression coefficient interpretation
- Ethics, limitations, and reflection

Logistic Regression was selected as the final model based on the evaluation
results. It achieved an accuracy of 80.06%, precision of 67.82%, recall of
47.33%, and an F1-score of 55.75%.
