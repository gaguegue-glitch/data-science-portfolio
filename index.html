About Me

Welcome to my data science portfolio. This portfolio highlights projects completed as part of my data science coursework and demonstrates my experience working with real-world datasets using Python, statistical analysis, visualization, and machine-learning techniques.

My projects focus on transforming raw data into meaningful information through data cleaning, exploratory data analysis, statistical modeling, machine learning, visualization, and interpretation.

The portfolio currently includes a household food-spending analysis using USDA FoodAPS data and a telecommunications customer-churn machine-learning project.

PROJECT 1

FoodAPS Household Food Spending Analysis

This project examines the relationship between preparing dinner at home and household food spending using data from the USDA National Household Food Acquisition and Purchase Survey (FoodAPS).

The project includes web data acquisition, data cleaning, merging, exploratory analysis, correlation, simple linear regression, multiple linear regression, and interpretation of the results.

Tools: Python, Pandas, Matplotlib, Seaborn, Scikit-learn, BeautifulSoup

PROJECT 2

Telecom Customer Churn Prediction

This machine-learning project predicts whether a telecommunications customer will churn using customer characteristics, service information, and usage patterns.

The project includes exploratory data analysis, preprocessing, leakage prevention, baseline modeling, Logistic Regression, Random Forest, model evaluation, confusion matrices, feature importance, and model interpretation.

Tools: Python, Pandas, Matplotlib, Seaborn, Scikit-learn
